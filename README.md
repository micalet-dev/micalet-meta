# Micalet Meta

Metapaquets oficials de la distribució Micalet.

## Característiques

- Distribució base: Ubuntu 26.04 LTS (Resolute).
- Arquitectura inicial: amd64.
- Generació de dependències: Germinate.
- Empaquetament: Debian.
- Publicació: Launchpad PPA.

## Contingut

- debian/: configuració dels paquets Debian.
- seeds/: definició dels metapaquets de Micalet.
- update.cfg: configuració de Germinate.
- update: actualització dels metapaquets.

## Branques

- main: versió estable.
- daily: desenvolupament.
